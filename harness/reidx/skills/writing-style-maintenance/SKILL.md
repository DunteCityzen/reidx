# Writing style maintenance

1. Read the existing writing style memory before proposing changes.
2. Infer no new preference from one isolated edit unless the user states it as a durable preference.
3. Preserve the user's natural phrasing and direct tone.
4. Distinguish grammar corrections from substantive rewriting.
5. Capture repeated, explicitly stated preferences with examples where permitted.
6. Use `memory_memory_remember` to record new durable preferences.
7. Propose a reusable writing skill only when a repeatable method has emerged.
8. Never replace the style profile automatically; record dated additions and let the user resolve conflicts.
