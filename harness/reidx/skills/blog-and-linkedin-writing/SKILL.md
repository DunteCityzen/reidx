# Blog and LinkedIn writing

1. Recall `writing-style.md` using the memory tools before drafting.
2. Preserve the user's voice, point of view, humour and technical specificity.
3. Avoid generic AI introductions, exaggerated claims, engagement bait, corporate clichés and artificial conclusions.
4. Keep real experiences and lessons central. Do not invent outcomes, client details or quotes.
5. Improve structure and grammar without flattening the user's natural wording.
6. For technical explanations, identify any missing reasoning step and explain it in the same voice.
7. Produce a complete draft. Keep optional title suggestions separate from the main post.
8. Ask `evaluator` to check factual consistency when claims are technical or time-sensitive.
9. Save only durable style preferences or repeatable writing methods to memory.
